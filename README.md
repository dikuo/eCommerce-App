# CaraStyle E-Commerce Platform

A professional full-stack MERN application featuring secure multi-gateway payments, containerized infrastructure, and automated end-to-end testing.

## 🔗 Live Deployments

*   **Frontend Application:** [https://carastyle-frontend.vercel.app/](https://carastyle-frontend.vercel.app/)
*   **Admin Dashboard:** [https://carastyle-admin.vercel.app/](https://carastyle-admin.vercel.app/)
*   **Backend API:** [https://carastyle-backend.vercel.app/](https://carastyle-backend.vercel.app/)

## 🛠️ Technology Stack

*   **Frontend:** React 19, Vite, Tailwind CSS, Context API.
*   **Backend:** Node.js, Express.js, MongoDB Atlas.
*   **Payments:** Stripe & PayPal integration.
*   **Testing:** Playwright E2E testing suite.
*   **Infrastructure:** Docker, GitHub Actions CI/CD, Vercel.

## 🚀 Key Features

*   **Complete CRUD:** Full product and order management via the Admin panel.
*   **Authentication:** Secure JWT-based user and admin login.
*   **Image Management:** Cloudinary integration for scalable product asset storage.
*   **Parallel Growth:** Architected for scalability and maintainable professional narratives.

## ⚙️ Setup & Installation

1.  **Clone the Repo:**
    ```bash
    git clone [https://github.com/dikuo/eCommerce-App.git](https://github.com/dikuo/eCommerce-App.git)
    ```
2.  **Environment Variables:**
    Configure `.env` files in `/backend` (MongoDB, Stripe, Cloudinary keys) and `/frontend` (`VITE_BACKEND_URL`).
3.  **Run Locally:**
    ```bash
    # In /backend
    npm start
    # In /frontend
    npm run dev
    ```
